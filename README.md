## 版本管理（git）

仓库就是本目录（`/vol1/1000/airesults/cdp`）。**源码 + 文档 + 证据 + 工具入库；构件不入库**——
APK 每个 42MB、一轮一份，进库会迅速膨胀；出处与校验靠 `apk/apk-sha256.txt` 与 `MANIFEST.txt`
（逐文件的大小 + sha256 都在库里，二进制不占地）。构建产物（`source/cdp/app/build`、`.gradle`、`__pycache__`）一并忽略。

每轮收工时的提交约定（跟归档四样一致）：

1. 更新 `docs/问题与需求登记.md`（B-编号）＋ `evidence/<n>-*.txt` ＋ README 的本轮小结；
2. `python3 tools/gen_manifest.py` 重算 MANIFEST；
3. `git add -A && git commit -m "B-xx 一句话（验收 N/N，构件 sha 前 12 位）"`。

查历史：`git log --oneline`｜看某一轮到底改了什么：`git show <sha> --stat`。

## 界面模块化（功能与运行代码解耦）

渲染层抽到 `assets/ui/modules/`，依赖单向（`app.js → modules → DOM`）：

| 模块 | 管什么 | 接口 |
|---|---|---|
| `fmt.js` | 小工具 | `mk / time / host / bytes / short / putEmpty` |
| `kv.js` | 键值对排版（键小字在上 / 值大字在下 / 横线） | `list / clean / fromRow / toText` |
| `modal.js` | **小窗渲染器**（唯一造小窗的地方）：键在上、**值一律文本框**（可改 / 只读同一长相），底部〔恢复原始值〕〔确定〕 | `open({title, fields, onSubmit, extras, options}) / show(…) / close / reset / scan` |
| `list.js` | 列表行渲染器（行 = 一条信息，点行弹窗） | `compact / compactAll / watch / scan` |

小窗的按键就是"每个键带它自己的小功能"：`{label:'下载', op:'download.start', args:{…}}` 或 `{label:'复制', run:fn}`。
自检：`__cdpModules()`（模块清单 + 行/小窗渲染者 + **重复 id** + `violations`）。详见 `docs/界面模块化.md`。

## 应用长什么样

顶栏：`◀` `▶` `⟳` 地址栏（点一下**全选**，直接打字替换，回车搜索/打开）录制指示灯 🕶 隐身指示灯 `☰`。
`☰` 是**下拉菜单**，弹在 ☰ 正下方：开始/停止监听、打开控制台、🎯 拾取元素、🔇 静音此页、📤 分享本页、历史、书签、脚本、接口。

控制台是**竖排抽屉式**（左上 `☰` 拉开；点遮罩或选中即收起），现在是**两级**：
**7 个归类集合 ▸ 每个集合下是它的栏目**（一行一个集合，点开才列出栏目），顶上还有一个"找功能 / 栏目"的搜索框。

```
浏览            页面与元素 · 窗口 · 页面工具
自动化          录制与回放 · 脚本 · 插件 · 终端与 ffmpeg
隐私与拦截      Cookie · 密码库 · 拦截与名单 · 安全与隐身
网络与媒体      网络 · 资源嗅探 · 下载
记录与归档      历史 · 书签 · 一键导出
接口与隔离      控制口 · 给 AI / 别的软件 · 配置空间
设置与系统      设置 · 省电与后台 · 日志 · 介绍与登记表
```

右上 `✕` 真的能关掉它；**控制台打开时，上面那排键依然可用**（浮层从工具栏下面开始，不再盖住它）。
这个两级结构不是手写的：`assets/ui/registry.js` 是功能登记表（45 个功能 / 45 个板块，一个功能只属于一个集合），
抽屉由它生成、板块按它挂载、启动时自检差值；界面里「介绍 ▸ 功能登记表」就能跑一次自检。

- **页面**：状态、找元素（选择器/文字）、可点击性诊断、按坐标/距底部点、视频状态与"播完了吗"
- **小点（坐标步骤的落点）**：坐标步骤在屏幕上画成**编号小点**（无障碍覆盖层，能盖在视频/播放器之上）；
  **点一下小点 = 让它自己点那里**，**拖动小点 = 直接改这一步的坐标**；元素步不画点但**序号照占**（页面上可能是 1 2 4）；
  同一个点连点几次自动合成一个点（角标 ×N），不同处的两个点可以合并成"一个点组"（仍然一步）。
  接口：`/api/record/dots?on=`、`/api/record/dots/status`、`/api/record/dots/play?n=`、
  `/api/record/dots/move?n=&x=&y=`、`/api/record/merge?index=`、`/api/geom`
- **坐标录制由原生层抓**：真实触摸在 Activity/WebView 那一层就记下来（跨域 iframe、原生视频表面、
  播放器手势里都逃不掉）→ 拿到点再回顶层页面问锚点，回放走同一套锚点；坐标步**只记真实手指**
- **两种录制方式**（同一个开关管所有入口）：控制台里选「元素录制 / 坐标录制」，**☰ 菜单那条「开始监听」也跟着变**
  （以前菜单那条漏传 mode，选了坐标录制也照元素录 —— 已修，菜单文案会写明当前方式）
- **监听**：先选**录制方式** ——「元素录制」（记选择器/文字，元素挪了也能找回来）或「坐标录制」（只看点在哪，
  适合 canvas / 播放器 / 反复重绘的地方）→ 开始监听 →（关掉控制台）在页面上点要点的按键 → 停止并保存；
  可随时**插入等待/播放/条件步骤**；两种录出来的步骤能混在同一个队列里回放；
  粘贴 JSON 导入录制脚本；回放显示**每步触发次数与累计运行次数**
- **脚本**：列表（录制脚本带运行计数）、删除、粘贴保存、从网址导入油猴脚本、扫描导入目录
- **设置**：浏览模式（手机/电脑/自定义 UA，应用后当前页会刷新）、搜索引擎（必应/百度/谷歌/搜狗/360 + 自定义模板）、
  **隐身模式**、**代理**（HTTP / HTTPS / SOCKS5 + 账号密码 + 直连白名单）
- **资源嗅探**：页面里出现的媒体地址自动记下来（hls `m3u8` / dash `mpd` / 视频 / 音频 `mp3 m4a aac flac …` / 字幕），
  按站点分组、能按类型筛（播放列表 / 视频 / 音频 / 字幕 / 分片）、能「只看当前页」；
  **同一路的分片合并成一条「分片 ×N」**（不刷屏）；还有「从页面里再找一遍」（performance 资源 + `video/audio` 标签）；
  每条点行弹小窗：下载 / 用内置播放器打开 / **转存 m4a·mp4（只换容器不重编码）** / 投屏 / 复制；
  **一键下载 m3u8**（连播放列表带分片按顺序存进 `downloads/<名字>.hls/`，不转码不合并）；
  音频可「下载全部音频」；对用了 MSE（`blob:`）的站点如实写明"直链不在请求层"
- **Cookie**：按域名查、**全局列表**（当前页 + 历史 + 书签里出现过的站点）、删单条、清空全部
- **历史 / 书签**：点条目真的开在浏览器里（不是把控制台自己导航走）
- **下载**：填地址就能下（存 App 私有目录，**不弹系统通知、不申请存储权限、不依赖外部 App**），
  列表显示大小/进度/状态，可删除；网页里的下载链接与长按菜单的「下载链接」走同一条链路
- **后台播放（熄屏 / 切到后台继续放）**：前台服务换成系统认可的 `mediaPlayback` 类型 + 持一把 partial 唤醒锁；
  页面**不会被 pause**，所以切出去或熄屏后音频继续走。（**故意不抢音频焦点** —— 抢了会把正在播的媒体掐停，实测踩过）
  控制口：`/api/keepalive/media?on=0|1`
- **接口**：HTTP 控制口开关（本机/局域网）、CDP 调试端口提示、接口清单
- **日志**：App 日志与页面事件

## 浏览器功能（第二轮补齐）

| 功能 | 做法与边界 |
|---|---|
| 浏览模式 | 手机（WebView 默认 UA）/ 电脑（桌面 UA）/ 自定义 UA；应用即刷新当前页 |
| 搜索引擎 | 内置必应/百度/谷歌/搜狗/360，可自定义 `%s` 模板；地址栏输入非网址时用它 |
| 隐身模式 | 不记历史；**关掉那一刻**清除 cookie / localStorage / 缓存与无痕期间的下载记录与文件。Android 的 CookieManager 是全局的，做不到"只清无痕的那部分"，这点在界面里写明了 |
| 代理 | 浏览器流量走 App 内的**本地中继**（127.0.0.1 随机口），中继再按设置连上游：HTTP / HTTPS（连代理本身走 TLS）/ SOCKS5，可带账号密码（WebView 自带的代理设置既不支持 SOCKS5 也填不了账号密码，所以绕一层）；直连白名单支持 `*` 通配；**只影响浏览器**，别的 App 不受影响 |
| 资源嗅探 | 在 `shouldInterceptRequest` 里登记媒体请求（只记录、不改动请求） |
| m3u8 下载 | 取播放列表 →（多码率主列表先取其中一路）→ 分片按顺序落盘 + 存 `playlist.m3u8` 与 `MANIFEST.txt` 供对账 |
| 外部协议 | `bilibili://` 这类深链拦下来自己处理（有 App 能接就唤起，没有就忽略并记日志），不再变成 `Webpage not available` |

## 安全（本轮加固）

| 面 | 做法 |
|---|---|
| 控制口绑定 | **默认只绑 `127.0.0.1`**；要局域网访问得显式 `?lan=1` |
| 访问令牌 | 绑局域网后，非本机调用必须带 `?t=<token>` 或 `X-CDP-Token`；令牌**每次启动随机生成**，本机免令牌；令牌只能在本机取（外部 403），界面里能看/能换一把 |
| 敏感接口 | `vault.*` / `cookie.*` / `eval` / `downloads/get` / `settings/set` / `export` / 空间切换 在局域网下**默认关闭**，要显式打开；被拒的请求回 **403 + 原因**，并记数、写日志（面板上能看到被拒次数） |
| 页面→原生 | 不往页面挂任何原生对象；虚拟源带**每次启动随机口令**，服务端没带口令一律 403 |
| 界面本身 | 控制台界面有 CSP（`default-src 'self'`，没有 `unsafe-eval`）：页面里 `eval` 会被拒；回包带 `nosniff` / `no-referrer` |
| 数据 | 密码库 AES/GCM + 锁屏验证；密文字段任何读接口都不回传；AI 取正文默认剔掉表单值与 cookie |

## 三个通道

```
① 控制台界面 ──(addWebMessageListener，按 origin 开放)─┐
② 本地/局域网 HTTP 控制口（默认只绑 127.0.0.1:8848）──┤──► Bridge（同一套 op 分发）
③ 页面事件（fetch 打虚拟源 https://cdp-event.local）───┘
```

页面 → 原生**不挂任何原生对象**（安全），走虚拟源 + `shouldInterceptRequest` 拦截；
用户脚本清单同样走虚拟源（`https://cdp-meta.local/meta`）同步取。

## 脚本能做什么（步骤类型）

| 类型 | 含义 |
|---|---|
| `click` | 点元素（DOM 指纹 + 位置锚点双保险；**不在视口就先滚进来**，注入真实触摸） |
| `wait` | 等固定毫秒 |
| `playVideo` | 播放页面里的视频（先注入真实触摸，再调 `play()`） |
| `waitFor` | **等条件成立**：视频播完 / 视频在播 / 元素出现 / 元素消失 / 文字出现 / URL 变化 / URL 包含 |
| `if` | **条件分支**：条件成立走 `then`，不成立走 `else` |
| `goto` / `input` | 打开网址 / 填输入框 |

典型"学习通式"脚本：`playVideo` → `waitFor videoEnded` → `if(元素出现) → click`。
真实触摸与 JS 合成兜底在返回值里分得清（`via` / `trusted`），不会把合成点击报成真实点击。
