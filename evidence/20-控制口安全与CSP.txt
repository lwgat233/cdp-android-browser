实现要点（代码里怎么落）
------------------------
· `HttpControl.authCheck()`：本机（127.0.0.1/::1/…）免令牌；绑局域网后非本机必须带
  `?t=<token>` 或 `X-CDP-Token`；敏感前缀（vault / cookies / downloads-get / history-清删 /
  settings/set / eval / export / space.use / http.* / ai.context / grab / security.token）
  在局域网下还要 `sensitiveLan` 打开才放行。拒绝一律 **HTTP 403 + 原因**（不是 200 里塞 error），
  被拒会记数并写日志（面板能看到"被拒 N 次"）。
· 令牌每次启动随机生成（UUID 去横线取 24 位）；只在**本机**能取（`GET /api/security/token`），
  非本机哪怕带对令牌也不回令牌本身；界面里的「看一眼令牌 / 换一把新令牌」走 App 内通道。
· 回包统一加 `X-Content-Type-Options: nosniff` 与 `Referrer-Policy: no-referrer`。
· 控制台界面加 CSP：`default-src 'self'; img-src 'self' data:; style-src 'self' 'unsafe-inline';
  script-src 'self'; connect-src 'self'; object-src 'none'; base-uri 'none'`。

测试自己踩到并改掉的两处（都写进 skill 了）
--------------------------------------------
1. **用 CDP 的 Runtime.evaluate 去 eval，验不出 CSP**：那是特权路径，不受页面 CSP 约束 ——
   第一版断言得到 blocked=false 的假结论。改成"让页面自己去取一个 CSP 不允许的外部图片，
   听 securitypolicyviolation 事件"，才真的能证明 CSP 生效（本证据里那条 violation 就是它）。
2. **别按 CRLF 硬切 HTTP 回包**：`subprocess(text=True)` 会做通用换行转换，CRLF 到手里已是 LF，
   按 CRLF+CRLF 切会切不开 → 正文带着响应头 → json 解析必然失败（第一轮 12/18 全是这类假红，
   服务器其实回的是标准 CRLF，是测试脚本自己切错了）。
3. 另外：脚本开头必须**先把状态归位**（打开敏感接口/绑局域网的操作会留在 App 里；
   上一轮中途崩过一次，导致这一轮"默认态"断言全红）。这就是 skill 里那条"先归位再断言"。
