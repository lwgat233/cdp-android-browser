==================================================
构件：apk/cdp-debug.apk（本轮改完重建，sha256 见 apk/apk-sha256.txt）
环境：Android 14 x86_64 模拟器
验收脚本：tools/verify_kv_recmode.py → **16 / 16 通过**（rc=0）

一、键值对排版（用户指定：键和值不在一行 —— 键小字在上、值大字在下、每对之间横线）
------------------------------------------------------------------------------
[1] 键值对排版：键小字在上、值大字在下、横线分隔
  PASS 键值对有多条（5 条）
  PASS 每一对是「键在上、值在下」的两行（DOM 顺序）→ ['kv-k', 'kv-v']
  PASS 两个不在同一行            → False（同一行=假，说明确实分成两行）
  PASS 键在上、值在下（纵向位置） → True
  PASS 值字号比键大              → [11, 15]（px）
  PASS 值与键颜色有层次（值更亮） → 键 rgb(122,135,148) / 值 rgb(234,242,250)
  PASS 键值对之间有横线          → 第 2 条的 border-top = 0.73px
  PASS 动作栏在（动作排在信息下面）→ 1 排

实现：`showModal(title, text, rows, actions, pairs)` 多了第 5 个参数 `pairs`：
  · 有 pairs → 每条渲染成 `<div class="kv"><div class="kv-k">键</div><div class="kv-v">值</div></div>`；
  · CSS：`.kv-k` 11px 灰蓝在上、`.kv-v` 15px 亮色在下、`.kv + .kv` 之间 `border-top: 1px solid #22303E`；
  · 行小窗（网络/Cookie/嗅探/下载/历史…）统一走这条排版。

二、录制两种方式：元素录制 / 坐标录制（用户要求"最好支持两种"）
--------------------------------------------------------------
[2] 录制两种方式
  PASS 元素录制：步骤带选择器                    → #divBtn
  PASS 元素录制：模式标成 element                → element
  PASS 坐标录制：步骤不带选择器（不看元素）       → （空）
  PASS 坐标录制：模式标成 coord                  → coord
  PASS 坐标录制：记下了位置锚点（cx/cy）         → [103, 313]
  PASS 坐标录制：记下了点击点的视口坐标          → [103, 313]
  PASS 坐标录制的脚本能回放（整体 ok）           → True
  PASS 回放用的是真实触摸（native-touch + trusted）→ ['native-touch', True]

实现（三层都改到了）：
  · 页面代理 `cdp-agent.js`：`recordStart(name, mode)` 记下模式；
    坐标模式下的点击**不记** 选择器 / DOM 指纹 / 诊断，只记 `box`（视口坐标）+ `anchor`（距顶/距底/纵向比例）
    + `mode:'coord'`，并在步骤里写明 note；子 frame 的镜像也带 `mode`（页面 meta 新增 `recMode`）。
  · 原生 `Bridge.startRecording(name, mode)`：把模式传给页面并记住（`recordMode`），
    meta 与 `rec.state/rec.live` 都回传模式；HTTP 路由 `/api/record?action=start&mode=coord` 可直接指定。
  · 界面：录制栏目多了「录制方式：元素录制 / 坐标录制」下拉；状态行写明当前模式；
    步骤摘要里坐标录制的点显示成 `坐标点击 (x, y)　坐标录制`。
  · 回放：坐标步骤没有可匹配的指纹 → 定位链直接落到位置锚点 → **注入真实触摸**（实测 trusted=True）。

怎么用（给人看的）
------------------
想在"元素反复重绘 / 就是一块 canvas / 播放器"的地方点，就选**坐标录制**；想在"按钮会挪但还在页面上"的地方点，
选**元素录制**（回放时指纹优先、丢了还能靠位置找回）。两种录出来的脚本可以混在同一个队列里回放。


五、顺手修掉的三个"验收脚本自己"的坑（不然会假红/假通过）
------------------------------------------------------
① 断言读的是旧的文字格式：字段现在渲染成 `.kv-k/.kv-v` 成对块，旧脚本还在数 body 里的"："→ 3 个板块假红。
   改成读 `#cdp-modal .kv-list .kv-k` 的对数（现在 29/29）。
② 回放对象抓错了：`/api/scripts` 列表**旧的在前**，`list[0]` 是"等视频播完"那种带等待条件的老脚本，
   在测试页上等不到 → 回放超时假红。改成用**停止回包里的 id**（`rec.stop` 返回 `{ok,id,...}`）回放刚录的那份 → 真过。
③ 控制口 URL 里的中文没编码 → 脚本名静默退回"录制脚本 N"，于是"按名字找刚录的脚本"永远找不到。
   改成 `quote("坐标录制")`。
