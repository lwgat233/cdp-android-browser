一、用户定的框架三条（已写成可执行规矩：docs/框架契约.md）
────────────────────────────────────────────────────────────────
1. 不做真插件包（不拆成独立 JAR/Dex/文件加载）——逻辑解耦、物理仍是一个 APK。
2. 可以拆成很多文件：原生一能力一文件一 object；界面一渲染器一文件 + 一份登记表。
3. 测试时只编动过的、只跑那部分的验收 —— 不整包、不跑全量。
4. 没接上的部分不许报错，也不许为了编译通过去改别的文件（可选依赖 + 默认实现）。

落地成四个工具（都在 source/cdp/tools/）：
  · fastcheck.sh     局部构建 + 局部验收。原生改动→只做 :app:compileDebugKotlin 增量（不 assembleDebug）；
                     UI 改动→连编译都不用（推到设备覆盖层，约 2 秒）；只有 --publish 才整包。
  · devpush.sh       UI 覆盖层：把改动的界面文件推到 /sdcard/cdp-dev/，控制口优先读它。
  · pick_tests.py    按功能 id / 改动文件，从 tools/test_map.json 挑出该跑的验收脚本（不跑全量）。
  · pack_test.sh     打"专门测某个功能"的测试版 APK，归档到 apk/测试版/，并写说明书。

界面覆盖层怎么自证（关键，避免又出"测的是哪一份"的假阳性）：
  控制口吐 ui/ 文件时带响应头 **X-CDP-Source: dev|apk**（dev=设备上推的那份，apk=打进构件的）；
  /api/dev/assets 列出当前覆盖了哪几个文件。已编进构件（HttpControl.kt）。

三、这一轮的坑（都是真踩的）
────────────────────────────────────────────────────────────────
K1 控制口的响应头是**手写字符串拼的**（没有 setHeader 这种 API）→ 想加响应头要往那段字符串里加；
   我照 HttpURLConnection 的习惯写 os.setHeader 直接编译不过。
K2 控制口路由表是"表达式 when"：分支必须是**返回 JSONObject 的表达式**；
   想直接写回包（writeJson 那种 Unit 函数）要像 /api/security/token 那样单独 if + return。
K3 **大 APK 装到模拟器会把它挂住**：这一次 `adb install -r`（42MB）之后 `adb shell` 全部超时、
   控制口死掉 → 装完立刻跑验收必假红。处置：装完先 `tools/env_health.py` 确认 READY 再干活。
K4 模拟器这一夜累计 **8 次异常**（7 次 SIGSEGV + 这次卡死），都在"重活"（连续真手指点击/媒体/下载/装大包）之后。

补记（同一夜稍后：覆盖层端到端跑通 + 一个真坑）
────────────────────────────────────────────────────────────────
**坑（真踩，值得记）**：覆盖层第一版把目录放在 `/sdcard/cdp-dev/` —— Android 11+ 分区存储下
**应用根本读不到那里**，请求直接失败（页面白屏、`/api/dev/assets` 只有目录没有文件），
现象看着像"覆盖层没生效"。改成**应用自己的外部目录**才通：
  `/storage/emulated/0/Android/data/dev.cdp/files/cdp-dev`
并且 `/api/dev/assets` 会把这个真实路径报出来，`tools/devpush.sh` 从接口读路径（不再写死）。

**端到端演示（真跑，四幕都过）**
```
① 推之前： curl -D- .../ui/modules/appgrid.js  →  X-CDP-Source: apk
② 推一个： tools/devpush.sh .../modules/appgrid.js → 1 个文件，无需重建 APK
③ 推之后： curl -D- .../ui/modules/appgrid.js  →  X-CDP-Source: dev
   页面刷新后格子文字 = ["控制台","历史","资源嗅探","省电","添加应用"]  ← 改的那一行生效
④ 撤回：   tools/devpush.sh --clear → X-CDP-Source 回到 apk
```
结论：**改一行界面 ≈ 2 秒见效，完全不重建 APK**（全量 assembleDebug 约 55 秒）。
这一条把"只测你动的那一个文件"落到了实处。
