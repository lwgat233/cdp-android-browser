# 界面规范：信息列表的行长什么样（用户 2026-09-21 定）

> 这是**行本身**的规范（点开的小窗另有规范：键小字在上、值=文本框、底部〔恢复原始值〕〔确定〕）。
> 所有列表（历史 / 书签 / 下载 / 网络时间线 / 嗅探 / 阅读 / 密码库 / Cookie …）**都按这一份来**。

## 一行 = 两行制：左列 + 右列

```
┌──────────────────────────────────────────────┬──────────────────┐
│ 第 1 行  标题            大字号 · 600 字重     │  时间            │
│ 第 2 行  网址 / 次要信息  小字号 · 灰色        │  流量 / 大小     │
└──────────────────────────────────────────────┴──────────────────┘
       左列：可压缩；**超长用「…」（三个点）截断**      右列：固定宽度、靠右
                                                  **数值必须完整显示，绝不许截断/省略**
```

## 四条硬规则

1. **标题大字号**：字号 ≥ 14px、字重 600；占第一行。
2. **网址/次要信息小字号**：字号 ≤ 12px、灰色；占第二行（同一行的左侧上下两行）。
3. **右列固定、数值完整**：时间、流量、大小、进度这类数**靠右固定**，
   `flex: 0 0 auto` + `white-space: nowrap`，**不允许 `text-overflow: ellipsis`** ——
   即：宁可标题被截，也不许把数字截掉（用户原话："必须要把后面的数显示出来"）。
   数字用等宽数字（`font-variant-numeric: tabular-nums`）对齐，竖着看成一列。
4. **只有标题（和次行的网址）才用「…」**：`overflow: hidden; text-overflow: ellipsis; white-space: nowrap`，
   且左列 `flex: 1 1 auto; min-width: 0`（否则 flex 不肯缩，省略号不会出现）。

## 对应到代码

- 行容器：`.row-item`（**两行用 `.two`**，高度按内容 `min-height: 44px`，不要写死 34px 把第二行切掉）。
- 左列：`.ri-main`（`flex: 1 1 auto; min-width: 0`）→ 里面 `.ri-t`（标题）+ `.ri-s`（次行）。
- 右列：`.ri-r`（`flex: 0 0 auto; text-align: right; white-space: nowrap; overflow: visible`）。
- 统一的行工厂：`CDPUI.Row.make({title, sub, right, fields, actions, kind})`
  —— **新列表一律用它**，别再各自 `mk('span','nm2')` 拼。

## 怎么验（判据是读回来的样式/宽度，不是"看着像"）

`tools/verify_list_rows.py` 会把每张列表的每一行读一遍并断言：

| 判据 | 读什么 |
|---|---|
| 标题是大字号 | 标题元素 `computedStyle.fontSize ≥ 14px` 且 `fontWeight ≥ 600` |
| 次行是小字号 | 次行元素 `fontSize ≤ 12px`，且它和标题在同一行的左侧上下排 |
| 右列是固定列 | 右列 `flexBasis == auto`（`flex: 0 0 auto`）、`whiteSpace == nowrap`、`textOverflow != ellipsis` |
| **数值完整** | 右列元素 `scrollWidth <= clientWidth + 1`（真被撑破就算不合规） |
| 标题才省略 | 标题 `textOverflow == ellipsis` 且 `whiteSpace == nowrap` |

任何一条不过 → 那一行会被点名（列表名 + 行序号 + 实测值），照着改。
