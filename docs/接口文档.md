**通用约定**

- 只监听本机：`http://127.0.0.1:8848`（手机自己调不需要令牌）。
- 从**局域网**访问（别的电脑/手机）：必须带令牌（`?token=…` 或 `X-CDP-Token`），否则 403；令牌在 App 的「控制口」栏目里看。
- 敏感接口默认关（网页控制、下载到系统、AI 上下文等），要去「控制口」里显式打开。
- 回包统一 JSON；出错是 `{"ok":false,"error":"…"}`。
- 页面类接口（goto / eval / click / query / diag）在**浏览器那个 WebView** 里执行；控制台界面走的是同一套 op（`CDPT.call(op, args)`）。
