## 统一验收口径（每个都要过）
1. **API 面**：`/api/...` 回包是读回来的事实（不是"看起来对"）。
2. **控件面**：真手指点（`adb shell input tap`，坐标现测、**点前先把目标滚进视口并把横向归零**、**点后读副作用，没生效就重试最多 3 次**）。
3. 渲染面：读回 DOM（元素个数/计算样式/选区），**不接受"图看着在"**。
