### 0. ✅ 已完成（仅文档，未动代码）"能不能用 Chrome 内核 / 嵌套一层监听全部网络字节"
用户问：能否用 Chrome 内核完成 WebView 做不了的事（cookie 等），甚至给 Chrome 嵌一层，让所有网络二进制都能监听。
结论与依据落在 `docs/方案-内核与网络监听.md`：
- **换内核不做**（安卓 WebView 内核就是 Chromium；CEF 安卓无可用发行版；外部 Chrome 只能电脑 adb 控）。
- 差距在**控制面**，而它的等价物是 **CDP**：cookie 全字段（`Network.getAllCookies` 含 httpOnly/secure/sameSite/expires/size）、
  请求/响应头逐字段、响应体（二进制 base64）、`Fetch` 域改写/伪造响应（合"不渲染而非硬阻断"）。
- "**所有**网络二进制"只有**本机 MITM**（App 内代理 + 自签 CA，只让自己 App 信任，不需 root）能保证全量；CDP 只给"缓存得下的体"。
- **两个未知点**：① ✅ 已实测 —— `CookieManager.getCookie()` **会**返回 HttpOnly 的 `name=value`（缺的只是标记）；
  ② App 内直连 devtools socket 仍未测（现在靠电脑 `adb forward`）。
- **本轮已修（用户点头后）**：① Cookie 属性"无效值"（B-82/B-83）—— 后端读库前先 `flush()`、加 `expiresMs`；
