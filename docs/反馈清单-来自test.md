### 这一轮修掉的真缺陷
1. **`ffmpeg-kit-min` 不带 TLS**：连无查询串的 `https://…mp4` 都报 `Protocol not found`（此前"验通"用的是本地 `http://` 源）。换成 `ffmpeg-kit-https`（LGPL，APK → 41.7MB）。
2. **拉 CDN 的 403**：要带浏览器 UA + **站点域名根的 Referer**（完整页面路径 ❌、CDN 自己的域名 ❌、空 ❌）；`-user_agent` 值带空格不加引号会把后面的 `-headers` 吃掉。
3. **嗅探格式表漏 `.m4s` 等**（B 站分片扩展名）。
4. **应用自带下载器**：直链被丢进 m3u8 通道（必失败）→ 加单文件通道；请求缺 Referer；启动时把上次被杀的"进行中"记录标成中断。
5. **屏幕录制在 Android 14 上完全不可用**（四层）：缺 `FOREGROUND_SERVICE_MEDIA_PROJECTION` 权限与前台服务 → 服务没及时进前台（通知渠道要提前建）→ 顺序必须是"起服务等就绪 → 取投影 → 建虚拟屏"（先取投影会被系统直接拒）→ 建虚拟屏前必须 `registerCallback`。
6. 我自己的事故：用脚本切片改 `MainActivity.kt` 时切错，造成头部野片段/函数重复，已修复（构建恢复通过）。
