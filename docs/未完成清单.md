## N1 ✅ 已完成（验收 9/9）删除屏幕录制等用不到的功能 + 清掉无障碍残留（尤其控件）
- **要做什么**：屏幕录制（rec-screen 那一块）删掉；与之相关的**无障碍权限残留全部清掉**——
  服务声明、`dot-perm` 类控件、界面里提到"无障碍"的文字、以及任何"现在用不到但还是摆着"的控件。
- **判据**：① 界面里搜不到「无障碍 / 权限 / 屏幕录制」这类入口（读 DOM 按键清单为空）；
  ② `AndroidManifest` 里 `BIND_ACCESSIBILITY_SERVICE` 与那个 service 节点已删；③ 重装后 `dumpsys package dev.cdp` 里没有它；
  ④ 相关 op / 路由（`dots.*`、`screen.record` 之类）返回"未知命令"而不是还能跑。
- **注意**：这是**删功能**，按规矩从外往里删：界面入口 → op → 存储字段；先把界面上的控件清光。

## N2 ✅ 已完成（验收 5/5） 嗅探的资源按"文件"分类，不按"视频/音频"分类
- **要做什么**：嗅探列表的分组改成**按文件种类**（扩展名/文件名），不再按 media kind（video/audio/playlist…）。
- **判据**：抓一页 → 列表里每条按扩展名分组（如 `.m3u8` / `.mp4` / `.ts` / `.jpg` / 其它），
  分组标题就是文件类型；原先的"视频/音频"字样不再出现。

## N3 ✅ 已完成（验收 8/8） 下载要下到**系统目录**（不是应用目录），并且下次更新清空旧的应用内下载
- **要做什么**：默认下载目录改成系统可访问的位置（`/sdcard/Download/…`，用 MediaStore 或公共目录写法），
  不再落在 `filesDir/downloads`；**本次更新时把应用目录里已有的旧下载清空一次**（并给出提示）。
- **判据**：下载一个文件 → 系统"下载"目录里真的出现它（`adb shell ls /sdcard/Download/…`）；
  升级后 `filesDir/downloads` 为空；下载列表里能看到文件的实际路径。

## N4 ✅ 已完成（验收 8/8） 首页小 app 添加后不渲染（页面在、没报错、就是不显示）
- **现象**（用户原话）：首页那个 APP"好像是空没起来"，加添加 APP 也不显示，虽有那个页面但不渲染。
- **我查到的原因（待修）**：首页有两个入口：⌂（走本机控制口，同源，能 fetch 到列表）与新标签页默认地址
  `https://appassets.androidplatform.net/ui/start.html`（**https 源**，混合内容策略 NEVER_ALLOW →
  `fetch('http://127.0.0.1:8848/api/apps/list')` 被浏览器拦掉 → 页面在、但列表永远空、也不报错）。
- **要做什么**：让两个入口都能拿到列表——新标签页默认地址在控制口可用时也用控制口那份；
  控制口不可用时，页面上给一句**明确的空态**（"这个入口读不到列表，点 ⌂ 打开首页"），不再静默空白。
- **判据**：分别从两个入口打开首页 → 网格都要有格子；添加一个 → 立即可见；DOM 里 `#apps .app` 数 = 列表条数 + 1（＋）。

## N5 ✅ 已完成（验收 5/5） 录制板块要更简洁：脚本列表挪到步骤框下面，运行/回放按键合并到那里
- **要做什么**：录制板块里，**步骤列表（可上下滑动的那个框）放上面**，
  **「录制脚本列表」挪到它下面**；「载入到步骤列表 / 运行 / 回放」这类按键**合并到这一处**，
  不要再在板块里散着摆（常驻按键 ≤3）。
- **判据**：DOM 顺序 = 步骤框 → 脚本列表；运行/回放/载入三个动作用真实点击都能生效；
  板块里可见的常驻按键数 ≤3。
