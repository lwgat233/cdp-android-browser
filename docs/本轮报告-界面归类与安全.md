# 本轮报告：界面归类 + 嗅探广度 + 控制口安全（2026-09-20 凌晨）

构件：`apk/cdp-debug.apk` 41715831 字节 sha256 `90c08cfbd0391e49c0c9cfad955a4c9620b2cc9fda5c1893c5bd51e1edcb37da`
环境：Android 14 x86_64 无头模拟器（真机未测）；控制口 127.0.0.1:8848；WebView devtools 9222

## 一、这轮改了什么

### 1. 界面按"先扁平、再归类"重做（用户反复要求的那套方法）
- 新增机器可读的**功能登记表** `assets/ui/registry.js`：46 个功能的扁平行表 → **7 个归类集合** → 24 个栏目 → 46 个板块。
  抽屉（集合 ▸ 栏目两级 + 找功能搜索）、板块归属、启动自检**全部由它推导**，不再是手写一排按钮。
- **重新归类**（原来塞错地方的都挪回去）：密码库从「录制」→ 隐私与拦截；多窗口 → 浏览；
  翻译 → 浏览 ▸ 页面工具；下载方式 → 网络与媒体 ▸ 下载；隐身 → 隐私 ▸ 安全与隐身；
  阅读时间/屏幕录制 → 自动化 ▸ 插件；接口类里混着的「多窗口/空间」各归其位。
- **合并简化**：三块 Cookie → 一块（一个列表 + 点行小窗）；广告拦截 + 屏蔽名单 → **一份规则库**
  （一个 `adblock.json`、一个匹配器、一套 op，老的 `security.block.*` 保留为别名指向同一份数据）。
- 落地两条硬规矩：**一个渲染入口**（清空重建；删掉每 1.5 秒满屏扫一遍的定时器）、
  **列表只给摘要 + 常驻按钮 ≤3**（第 4 个起进「更多 ▾」，全界面 8 处；`__cdpButtonRows()` 可查）。
- 界面里多了「介绍 ▸ 功能登记表」：一点就跑自检（重名 / 没归属 / 登记了但页面上没有 / 页面上有但没登记）。

### 2. 嗅探广度（视频 / 音频 / 多网站）
- 扩展名认全：hls `m3u8` · dash `mpd` · 视频 `mp4 m4v m4s fmp4 cmfv f4v webm mkv flv` ·
  音频 `mp3 m4a m4b aac flac opus ogg oga weba wav` · 字幕 `vtt srt ass`；每条带站点/文件名/归类。
- **同一路分片合并成「分片 ×N」**（实测 6 次取片 → 1 条），不再刷屏；多了一列「只看当前页」（清空后旧页面会重新登记）。
- 第二条抓取路径「从页面里再找一遍」：performance 资源 + `video/audio/source`；MSE（`blob:`）站点如实说明边界。
- 行的动作进小窗：下载 / 播放 / **转存 m4a·mp4（只换容器不重编码）** / 投屏 / 复制；加了「下载全部音频」。

### 3. 控制口安全（本轮新做的加固）
- 默认只绑 `127.0.0.1`；**绑局域网后非本机必须带令牌**（`?t=` 或 `X-CDP-Token`），令牌每次启动随机生成、只在本机能取；
- **敏感接口**（vault / cookie / eval / downloads-get / settings-set / export / 空间切换）在局域网下**默认关闭**，要显式打开；
  拒绝一律 **403 + 原因**，被拒会记数写日志（面板可见），界面里新增「安全与隐身 ▸ 控制口安全」板块；
- 控制台界面加 CSP（`default-src 'self'`，无 `unsafe-eval`）；回包加 `nosniff` / `no-referrer`。

## 三、回归挖出的三个真缺陷（都是"静默失效"型）

1. **原生推给控制台的消息是字符串，界面当对象用** → 元素拾取回灌、状态推送**整条链路静默失效**
   （现象：拾取了但"找元素"框空的）。修：界面入口加 `asObj()`（字符串先 parse）。
   修后实测：`#q-sel` 真的变成 `#divBtn`、提示文字跟着变。
2. **替换嗅探栏目 HTML 时吞掉了两个板块**（`sniff-add` / `sniff-note`）→ 三个键成死键。
   是**功能登记表自检**报出来的（{"problem":"登记了但 HTML 里没有这个板块"}），补回后归零。
3. 嗅探列表的「下载」键调的是**不存在的 op 名**（`download` → 应为 `download.start`），点了没反应也不报错。

细节与定位过程见 `evidence/21-`。

## 四、未闭环 / 已知限制（不掩盖）

- **播放器页「下载 m3u8」那条断言未闭环**：两次跑各失败一次，都在模拟器开始崩场的同一轮里；
  没能在干净环境下单独复测完（模拟器随后 segfault 掉）。这是本轮唯一没验完的一条。
- **模拟器在本轮崩了 4 次**（`Exited (139)`，SIGSEGV），都发生在连续跑长套件时；分段跑 B 是在重启后干净跑完的。
  现场与处理纪律见 `evidence/19-`。分段 A 崩前 **38 PASS**，其中 iframe 录制与投屏那两组在更早的整轮跑里是通过的
  （崩场时的失败不作为结论）。
- **真机未测**；Doze 长挂未验证；MSE 站点的正片直链拿不到（界面里已如实写明边界）。
- `ffmpeg` 只换容器不重编码：HLS 音频能转存 m4a，**不能**重编码成 mp3（按钮文案与文档都没暗示可以）。
- 模拟器容器里 DNS 对部分境外域名解析错误（archive.org → `face:b00c` 段），宿主同地址正常 → 判为环境问题；
  音频链路因此用离线靶子保证可复现。
