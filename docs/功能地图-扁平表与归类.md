# 功能地图：扁平表 → 归类集合 → 界面载体（CDP 项目）

> 这份文档就是那套方法在本项目上的落地，也是**唯一的功能登记口径**：
> **① 先把功能在后端做全 → ② 列成扁平的二维表（先不管界面怎么摆）→
> ③ 归类到若干集合里（一个功能只属于一个集合）→ ④ 每个功能配一个界面载体 + 稳定标识。**
>
> 机器可读的那一份在 `source/cdp/app/src/main/assets/ui/registry.js`：
> **抽屉由它生成、板块归属由它决定、启动时自检差值** —— 文档和代码不会各说一套。
> 自检入口：`window.__cdpRegistry()`（界面里也有：介绍 ▸ 功能登记表）。

## 0. 命名与标识约定

| 层 | 标识 | 例子 |
|---|---|---|
| 归类集合 | `coll` 字段 | `browse` / `auto` / `privacy` / `media` / `records` / `api` / `system` |
| 栏目（载体容器） | `tab` 字段 + DOM `section#tab-<key>` + `data-coll` | `tab-block`、`data-coll="privacy"` |
| 板块（一块界面） | `board` 字段 + DOM `data-board` / `data-tab` / `data-order` | `block-rules`、`cookie-main` |
| 交互元素 | `id` / `contentDescription` | `ab-toggle`、`h-more`、`sn-scan`、`drawerBtn` |
| 运行时状态 | 状态快照 JSON key | `window.__cdpRegistry()`、`__cdpBoards()`、`__cdpMissing()`、`__cdpButtonRows()` |

有了这套标识，验收脚本不用"看像素猜坐标"：
抽屉里的每个键在无障碍树里都带 `resource-id = 元素 id`（实测：`collhead-api`、`tabbtn-space` 都能直接取 bounds 真点）。

## 2. 归类集合（7 个，一个功能只进一个集合）

### 浏览（`browse`）6 个功能

看网页这件事本身：页面 / 窗口 / 页面工具

栏目：页面与元素（`page`，4 个功能） · 窗口（`win`，1 个功能） · 页面工具（`tools`，1 个功能）

前缀：page · tools · win

### 自动化（`auto`）10 个功能

让它自己动：录制回放 / 脚本 / 插件 / 终端与 ffmpeg

栏目：录制与回放（`rec`，4 个功能） · 脚本（`scripts`，2 个功能） · 插件（`plugins`，3 个功能） · 终端与 ffmpeg（`term`，1 个功能）

前缀：plugin · rec · scripts · term

### 隐私与拦截（`privacy`）5 个功能

Cookie / 密码库 / 拦截规则与名单 / 安全与隐身

栏目：Cookie（`cookies`，1 个功能） · 密码库（`vault`，1 个功能） · 拦截与名单（`block`，1 个功能） · 安全与隐身（`security`，2 个功能）

前缀：block · cookie · security · vault

### 网络与媒体（`media`）7 个功能

请求时间线 / 网络工具 / 嗅探 / 下载

栏目：网络（`net`，2 个功能） · 资源嗅探（`sniff`，3 个功能） · 下载（`downloads`，2 个功能）

前缀：download · net · sniff

### 记录与归档（`records`）3 个功能

历史 / 书签 / 一键导出导入

栏目：历史（`history`，1 个功能） · 书签（`bookmarks`，1 个功能） · 一键导出（`bundle`，1 个功能）

前缀：bookmark · bundle · history

### 接口与隔离（`api`）6 个功能

HTTP 控制口 / 外部 CDP / 给 AI 的接口 / 配置空间

栏目：控制口（`api`，4 个功能） · 给 AI / 别的软件（`ai`，1 个功能） · 配置空间（`space`，1 个功能）

前缀：ai · api · space

### 设置与系统（`system`）8 个功能

浏览模式 / 搜索 / 代理 / 省电与后台 / 日志 / 介绍

栏目：设置（`settings`，3 个功能） · 省电与后台（`power`，1 个功能） · 日志（`log`，1 个功能） · 介绍与登记表（`intro`，3 个功能）

前缀：set · sys

## 3. 载体按粒度选（大 / 中 / 小 / 状态）

| 粒度 | 载体 | 本项目的例子 |
|---|---|---|
| 大功能（要整屏、有生命周期） | 独立页面 / 全局窗口 | 浏览器本体、控制台整体、多窗口面板 |
| 中功能（一类参数、一组开关） | 可折叠区块 / 栏目 | 「设置」「代理」「录制与回放」这些卡片；一行摘要 + 点开才展开 |
| 小功能（**单条数据**的编辑/操作） | **列表行 → 点一下弹出的小窗** | 历史/书签/Cookie/下载/脚本/嗅探/拦截规则/录制步骤/阅读记录：行里只有摘要 + `⋯`，动作（下载/播放/投屏/转存/复制/删除/移到文件夹）都在小窗里 |
| 状态 | **一行文字** | `拦截：已开启　广告规则 43 条 …`、`当前：隐私与拦截 › 拦截与名单`、`后台前台化：没开` |

两条硬规矩（违反了就是重写）：

- **R1 一个渲染入口**：状态变了就"清空 + 按数据重建"，**绝不追加节点**；同一栏目只在一个地方调它的刷新函数
  （`setTab()` 里的那张 `L` 表就是唯一入口，别处不再各写一份）。以前那个 `setInterval(compactAllRows, 1500)`
  每 1.5 秒满屏扫一遍的做法已经删掉（省电栏目也管这个）。
- **R2 列表只给摘要，点一下才出详情**：详情是固定模板、可上下滑、底部一组 `关掉`；
  **常驻按钮 ≤ 3 个/行**，第 4 个必须收进 `更多 ▾`（本轮用 `bindMoreBoxes()` 统一实现，界面上 8 处用了它）。

## 4. 交叉用跳转，不重复挂载

- 「一键导出」（记录与归档）里的 `历史 / 书签 / 脚本 / 拦截规则` 只是**导出项的名字**，功能本体仍在各自集合；
- 阅读与停留时间（插件）在记录集合里不重复出现，只在文档与介绍里指路；
- 「拦截与名单」里站点的警告条是**页面顶部**那条红字（浏览集合的界面），规则本体在隐私集合 —— 一个入口，一份实现；
- `☰` 下拉菜单里的栏目（开始监听 / 打开控制台 / 历史 / 书签 / 脚本 / 接口）都是**跳转入口**，
  点完落到对应栏目，不复制控件。

## 5. 为什么这么分（参照过的真实做法）

| 项目 | 做法 | 这里采用的部分 |
|---|---|---|
| VS Code `contributes` | 命令扁平声明（title/icon/category/when），由 `menus` / `viewsContainers` 决定出现在哪；命令面板按 category 分组 | 功能先扁平登记，用"归类集合 + 栏目"决定入口；抽屉与板块挂载由登记表推导 |
| Home Assistant `manifest.json` | 每个集成一份清单（domain / integration_type / iot_class），界面与注册表由清单生成 | 每个功能一条记录（id/名称/集合/栏目/板块/载体/标识/状态），文档与验收脚本都从这张表推导 |
| Backstage 软件目录 | 目录太细碎就"难以整体理解" | 45 个功能必须再归类成 7 个集合，否则"看着就累" |
| Nextcloud Android `preferences.xml` | `prefs_category_*` 是唯一父节点，每个开关只挂一个分类 | 一个功能一个分类；本项目用手写的两级抽屉（集合 ▸ 栏目） |
| 本项目前身 clicker（队列连点器） | 同一套方法在原生 Android 上用 XML 落地（`方案行 → 点开编辑小窗`、`≤3 键/行`、状态文字） | CDP 是 WebView 界面，方法照搬，载体换成卡片 / 列表行 + 小窗 |

## 6. 怎么加一个新功能（三步，别跳步）

1. **后端先做全**：op 加到 `Bridge.kt`（`<模块>.<动作>`），要能被外部调用就顺手加 `HttpControl.kt` 路由 +
   `ApiCatalog.kt` 一行；**先在 HTTP 控制口上 curl 通**，再谈界面。
2. **登记表加一行**：`registry.js` 的 `FEATURES` 里加 `{ id, name, coll, tab, board, order, carrier, entry, testid, status }`；
   如果是新的归类/栏目，先在 `COLLECTIONS` / `TABS` 里加（集合总数控制在 5~7 个）。
3. **界面加板块**：`index.html` 里加 `<div class="card" data-board="…" data-tab="…" data-order="…">`（元素先到场），
   再去 `app.js` 里加监听（**用 `bindMaybe(id, 'click', fn)`**，别用 `$('id').addEventListener`）与刷新函数，
   并把它挂进 `setTab()` 的 `L` 表。改完跑：`window.__cdpRegistry()` 自检 + 死键扫描 + 真手指脚本。
