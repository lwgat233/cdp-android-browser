# 功能规格（功能 → 板块 → 按键/交互 → 判据）

> 这份是**规格**：每个功能「是什么、有什么功能点、对应哪些按键、怎么算做到」。
> 机器可读的那份是 `assets/ui/registry.js`（抽屉与板块由它生成）；
> 缺口清单由 `tools/check_coverage.py` 自动算出来，写在 `docs/覆盖自检.md`。
> 规矩：**新加功能先在这里写清楚，再接控件、再补测试**；三者缺一项就算「开发不足」。

# 功能规格 · 逐板块（每个板块要能干哪些事 / 对应哪些按键 / 怎么算做到）

> 写法约定（用户要求的那套）：
> **一个板块 = 一组功能点**；每个功能点写清楚 **它对应哪个按键或输入**、**怎么算做到（判据）**、**现状**。
> 判据一律是**读回来的事实**（队列 JSON / 小点状态 / 下载字节 / DOM 状态），不是"看起来对了"。
> 缺口不写在正文里绕过去，而是交给 `tools/check_coverage.py` 自动报（见 `docs/覆盖自检.md`）。

## 自动化 ▸ 录制与回放

### `rec-list` 录制脚本列表（用户要求：放在录制板块里）
每行＝名称 + "N 步 · 时间 · 跑了 x 次（成功 y 次）"；**点行＝小窗**，动作
〔载入步骤〕（`rec.load`：把那条脚本的步骤深拷贝进步骤编辑区，可改可回放）〔运行〕〔✕删除〕。
脚本栏目那张表只列**用户脚本**（内置 / 粘贴的），录制脚本不再混在里面。

### `rec-1` 监听与录制（一个列表干完所有事）
**要能干的事**
1. 选录制方式：**元素录制**（记选择器/文字，元素挪了也能找回）/ **坐标录制**（只看点在哪，不看元素）。
2. 开始监听 / 停止并保存 / 清空步骤（清空要连小点一起重画）。
3. **步骤列表**：一行一步，序号连续（元素步不画点但占号，所以屏幕上的小点可能是 1 2 4）。
4. **列表最底部固定一行「＋ 添加步骤」**（用户要求的形态）：点开选形态 → 填参数 → 加到列表末尾，可以一直加；
   不用先开监听。
5. 每一行：**点行=打开可编辑小窗**（键在上、值是文本框；「类型」只读，其余可改）；▲▼ 换顺序（第一步没有 ▲、最后一步没有 ▼）；
   小窗里只有真做事的键：`▶ 只执行这一步` / `⇤ 并进上一个点`（**只在前面真有点时才有**）/ `✕ 删掉这一步`，加底部 `恢复原始值` + `确定`。

| 功能点 | 对应按键/输入 | 判据 | 现状 |
|---|---|---|---|
| 切换录制方式 | `select#r-mode`（选完立刻同步原生） | 原生 `mode` 与界面一致；☰ 菜单那条也跟着变 | 已做 |
| 开始 / 停止 | `#r-start` `#r-stop` | 原生 `recording=true/false`；停止后脚本进列表 | 已做 |
| 清空 | `#r-clear` | 队列 0 条 + 小点 0 个 | 已做 |
| **添加步骤** | `#r-add`（列表底部那行）→ 形态清单（**7 行可点行**，不占按键）→ 填参数 → `确定` | 队列多一条且类型/参数对得上 | 已做（verify_steps 24/24、verify_step_add 16/16） |
| 编辑一步 | 点行 或 行上的 `⋯ 操作` → ✎ 编辑这一步 | 读回来 `cy=400`、锚点同步、小点屏幕位置跟着挪 | 已做（[4]） |
| 排序 / 删除 | 行上 `▲` `▼` / ⋯ 里 `✕ 删掉这一步` | 队列条数与顺序变化对得上 | 已做（[6]） |
| 坐标录制抓取 | 真手指点页面（原生层抓） | 1 条 `mode=coord`、无选择器、带锚点；同处连点合成 1 条 `reps=N` | 已做 |

（原来的「② 插入一步」板块已取消：它就是列表底部那个加号；「③ 导入脚本」挪到 **脚本** 栏；
「④ 回放」仍在录制栏最后，按用户要求不动它。）

### `rec-dots` ①b 小点（坐标步骤在屏幕上的落点）
**要能干的事**
1. 把每个**坐标步骤**画成**编号小点**；**元素步不画点但序号照占**（所以页面上可能是 1 2 4）。
2. **单击小点 → 打开这一步的小窗**：先看/改信息（坐标、连点次数、点完等多少毫秒…），要跑再按「▶ 点这一下」。
3. **拖动小点 → 直接改这一步的坐标**。
4. 开/关小点；显示覆盖层是否可用（无障碍是否已授权）；一键跳到系统无障碍设置。
5. 状态色：待执行 / 当前 / 已执行；连点次数显示 `×N`。

| 功能点 | 对应按键/输入 | 判据 | 现状 |
|---|---|---|---|
| 画点（坐标步） | 自动（队列变化即重画） | `dots/status.count` = 坐标步数；日志「小点覆盖层：画了 N 个」 | 已做 |
| 不画元素步 | — | 队列「坐标/元素/坐标」→ 页面点是 `['1','3']` | 已做 |
| 单击看/改 | 小点自身 | 小窗打开、标题含"第 N 步"、有可改字段 | 已做 |
| 拖动改坐标 | 小点自身（拖） | 步骤 `box/anchor` 跟着变；回放用新坐标 | 已做 |
| 开关 | `#dot-toggle` | `dots/status.on` 跟着变 | 已做 |
| 去开权限 | `#dot-perm` | 跳到系统无障碍页；授权后 `overlay=true` | 已做 |
| 回放期间不可触摸 | 自动（`setBusy`） | 一次真手指点击 = 恰好一次「自己点第 N 步」 | 已做（踩过成环，见问题登记 B-11/B-12） |

### `rec-2` ② 插入一步（录制中随时插）
选类型（等几秒 / 等条件 / 点元素 / 条件点击 / 播放视频…）+ 参数（选择器 / 文字 / 毫秒）→ 插到队列。判据：队列多一条且参数一致。

### `rec-import` ③ 导入录制脚本 · `rec-4` ④ 回放
- 导入：粘贴 JSON → 保存为脚本；清空输入。
- 回放：下拉里**只列能回放的脚本（录制/队列，按时间从新到旧，默认最新那条）** + **次数框**（默认 1，非法→1，1..50）→
  「回放这条脚本」/「▶ 跑当前队列」/「刷新列表」；输出「跑 N 次：成功 M 次，总耗时」+ 逐次结果；每步有**触发计数**（成功率看得见）。
- 单步：步骤小窗里有一项**「跑几次」**，「▶ 只执行这一步」按它跑 N 次（这是执行参数，不会存进脚本）。
- 判据：`/api/replay?script=` 返回 `ok=true`、`steps[].via` 有值；坐标步必须是**真实触摸**（`trusted=true`）。

### `rec-screen` 屏幕录制（插件）
叫出系统录制授权 / 停止并保存 / 看状态。判据：状态接口能读出是否在录、产出文件字节 > 0。

## 自动化 ▸ 脚本 / 插件 / 终端
- `scripts-list` 用户脚本列表：列表 + 运行计数；点行看详情；删除。
- `scripts-paste` 粘贴 / 从网址导入脚本；导入要提示"命中哪些站点"。
- 内置插件（assets/scripts/*.user.js）首次启动自动装入、删了不再自动装；**跟着构件升级**：
  ScriptStore 的 `srcHash`/`codeHash` 双哈希 —— 用户没改过就覆盖为新版，改过就不动用户的版本。
- `阅读时间` 内置插件：**边看边报**（页面可见才计时，每 15 秒上报一次增量，切后台/离开补齐），
  不再有"正文少于 60 字就不计时"的限制；页面上那个小徽标点一下可立刻结算。
- `read-list` 阅读与停留时间：列表（排序 / 搜索 / 删除）；**我们自己的页面不记**。
- `read-chart` **统计**（一块，两个数据源共用）：读 `read.stats` / `net.stats`（都带 `range=hour|day|month|year`），
  交给 `modules/chart.js` 画**双色堆叠柱状图**（下面＝前台/下行，上面＝后台/上行；桶上标"时长·网站数"）
  与**饼图**（阅读按站点时长占比 / 流量按站点字节占比）；摘要一行给合计、前台/后台、连续使用（段数/最长/当前）。
  - 粒度还有 **「实时（现在）」**（排第一、默认）：摘要＝正在读 X（+Y）· 今天 A（前台 B / 后台 C，N 条）·
  连续使用 D · 最后更新 HH:MM:SS；每 5 秒自动刷新（只在统计板块可见时跑，切走即停）+ 最近 10 条数据表。
  数据存在本机（`files/read_log.json`），刷新/重载都不丢。
- `term-main` 伪终端 + 内置 ffmpeg：命令解析器，`cd/ls/ffmpeg …`；判据：输出里出现预期文本。

## 浏览

- **工具栏「▤」= 窗口列表**：每行 [●/○ 页面标题]（**整行可点＝切到那个窗口**）+ [✕]（关掉**这一个**窗口），
  最后一行「＋ 新窗口」；窗口名用**页面标题**；只剩一个窗口时 ✕ 不生效（如实提示"不能关"）。
- `page-status` 当前页面：下一个 / 上一个 / 清除高亮 / 刷新状态 / 🎯 拾取元素 / 收藏 / 静音此页 / 分享（更多 ▾ 收起来的那些）。
- `page-query` 找元素：选择器或文字（二选一）+ 查找 / 可点击性诊断 / 点它。
- `page-click-xy` 按坐标点 / 距底部点（真实触摸）。
- `page-video-cond` 视频状态与"播完了吗"的条件检查。
- **多窗口（已按用户要求改）**：控制台里**没有**这一栏；新建 / 切换 / 关闭只在浏览器**地址栏后面那个「▤」图标**里。
  窗口名字＝**页面标题**（标题空才退回主机名/地址），不再叫「窗口 1」；每个窗口各自记地址/标题/静音/屏蔽。
- `tools-translate` 翻译：端点可配；**没配就说没配**（不许假装翻译）。

## 网络与媒体
- `net-timeline` 请求时间线：最近的包与协议、上行/下行统计、可筛选。
  **「统计图」是跳转入口**：切到统计板块并把数据源设成「网络流量」（同一块统计，不重复挂控件）。
  上/下行只统计**应用自己搬运**的字节（应用内下载 / m3u8 分片 / **本地中继转发**）；页面内流量 WebView 不给，拿不到就不编。
- `net-tools` 网络工具：网速 / 通路 / 证书 / 按字段看报文。
- `sniff-list` 嗅探：hls/dash/视频/音频**含 mp3**/字幕；分片合并；只看当前页；下载全部音频/m3u8；点行看这条的全部信息（下载/播放/转存/投屏/复制）。
- `sniff-add` 手动加地址 / 下载 / **用内置播放器打开** / **看播放器状态**（`/api/player/state`：是不是播放器页、
  有没有 video、播放还是暂停、当前秒数 / 总时长）；`sniff-note` 说明与边界（MSE 的 `blob:` 抓不到，如实写）。
- 实测口径（樱花动漫 yhtn.cc）：真链可能藏在**跨域 iframe** 里，页面自己的 `<video>` 是空的 —— 这时以**嗅探清单**为准；
  我们自己的内部通道（appassets / cdp-event.local / cdp-meta.local / 127.0.0.1）**不进**清单与网络时间线。
- m3u8 下载记录带 `segsDone/segsTotal/bytes`，行上显示「100/1999 片」；**目前没有"取消下载"**（边界，要就另开）。
- `downloads-list` 下载：列表（大小/状态/存放位置）+ 删除（**问是否连文件一起删**）。
- `downloads-mode` 下载方式：内置 / aria2 等。

## 记录与归档
- `history-list` 历史：分页 + 下拉自动加载、按域名/时间删、导出（下载目录 / JSON）；
  **行是两行**（第一行标题＝点它开浏览器、第二行地址 + 日期，统一 54px 高、整宽）；
  **点行＝可编辑小窗**（标题可改，时间/地址只读），附加键「在浏览器里打开」。
- `bookmark-tree` 书签：文件夹树、加/删/改文件夹、点条目在浏览器打开（不是把控制台导航走）；
  **行同样两行**（标题 / 地址 + 文件夹）；**点行＝可编辑小窗**（标题 / 地址 / 文件夹都能改），附加键「✕ 删掉这条书签」。
- `bundle-export` 一键导出 / 导入（zip）：选要带哪些栏目。

## 隐私与拦截 / 安全
- `cookie-main` Cookie：按域名查 / 全局列表 / 删单条 / 清空；**点一行＝可编辑小窗**（值/路径/有效期/Secure/HttpOnly），
  列表**最底部有「＋ 添加 cookie」**；行里不摆按键（写回走 `cookie.set`，写完读回确认）。
- `vault-main` 密码库：**锁屏验证后才看/改**；随机密码（大小写/特殊字符可自选）；登录时提示是否保存。
- `block-rules` 拦截与名单：广告规则 + 隐藏选择器 + 站点警告名单。
- `security-page` 网站安全（当前页 + 证书）；`security-incognito` 隐身模式；`security-http` 控制口安全（令牌 / 局域网拒绝 / 敏感接口）。

## 接口与隔离
- `api-http` 控制口开关（本机 / 局域网）；`api-endpoints` **接口清单**；`api-catalog` 接口目录与组合接口（batch）；`api-cdp` 外部 CDP 调试端口提示；`api-ai` 给 AI 的接口（不给 cookies 等隐私）；`api-space` 配置空间（历史/书签/脚本/设置各一套）。

## 设置与系统
- `settings-mode` 浏览模式（手机 / 电脑 / 自定义 UA）；`settings-search` 搜索引擎（含自定义模板）；`settings-proxy` 代理。
- `power-list` 省电与后台；`bgplay` 后台播放（前台服务 mediaPlayback + 唤醒锁，熄屏继续放）。
- `log-tail` 日志；`intro-about` 介绍与版本；`intro-howto` 怎么用（三句话）；`sys-registry` 功能登记表（自检结果给用户看）。
