说明（边界，别当成 bug 报）

    

      ① 每条资源一行摘要，点行弹小窗：下载 / 用内置播放器打开 / 转存 m4a·mp4（只换容器不重编码）/ 投屏 / 复制；

      ② 同一路的分片（.ts / .m4s）合并成一条「分片 ×N」，不会把清单刷爆；

      ③ 用了 MSE（blob:）的站，直链不在请求层 —— 小窗里会说明，此时可看清单/分片，或换一个不是 MSE 的站；

      ④ 「只看当前页」：清空之后还在播的旧页面会重新登记，勾上它只看当前页。
